# Easy Sell (Tupla)

> Plataforma de commerce + agente de WhatsApp para tiendas: catálogo, cotizaciones, pedidos, pagos, envíos y atención al cliente, todo bajo una misma API y un servidor MCP para que cualquier agente de IA opere tu tienda con una API key.

Easy Sell expone sus funciones a través del Model Context Protocol (MCP). Un agente conectado puede leer el catálogo, crear cotizaciones, abrir pedidos con link de pago, responder mensajes de WhatsApp y más — todo autenticado por API key, con principio de menor privilegio y trazabilidad completa.

## MCP (Model Context Protocol)

- [Qué cubre el MCP de Easy Sell](https://easysell.tupla.dev/ayuda/conectar-por-mcp): cómo funciona, qué herramientas descubre el agente, qué NO puede hacer.
- [Editar el catálogo con un asistente](https://easysell.tupla.dev/ayuda/mcp-catalogo): casos de uso reales del agente conectado, qué le puedes pedir.
- [Rotar y revocar API keys](https://easysell.tupla.dev/ayuda/rotar-y-revocar-api-keys): cuándo y cómo rotar claves sin cortar el acceso al agente.
- [Multi-tenant y keys globales](https://easysell.tupla.dev/ayuda/multi-tenant-y-keys-globales): un agente atendiendo varias tiendas, soporte de plataforma, variable `COMMERCE_TENANT_ID`.
- [Preguntas frecuentes API y MCP](https://easysell.tupla.dev/ayuda/preguntas-api-mcp): errores 401/403, key perdida, agente sin permisos.
